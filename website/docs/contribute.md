# Contributing guide

By contributing, you agree to the [OpenEverest code of conduct](https://github.com/openeverest/governance/blob/main/CODE_OF_CONDUCT.md).

Ways to help:

- Submit bug reports or feature requests
- Submit a code patch
- Improve documentation

## Bug reports and feature requests

Search existing [OpenEverest issues](https://github.com/openeverest/openeverest/issues) first. If nothing matches, open a new issue that:

- describes how to reproduce the problem
- includes the OpenEverest version and environment
- covers a single bug or request

## Code

Follow the [contributing guide in the OpenEverest repository](https://github.com/openeverest/openeverest/blob/main/CONTRIBUTING.md).

## Documentation

This Docusaurus PoC lives in `website/` of [openeverest/everest-doc](https://github.com/openeverest/everest-doc). The production MkDocs sources remain in the repo-root `docs/` directory.

1. Open an [everest-doc issue](https://github.com/openeverest/everest-doc/issues) for typos or missing pages, or
2. Edit the Markdown, open a pull request, and wait for a maintainer review.

Use [Markdown](https://www.markdownguide.org/getting-started/), [git](https://git-scm.com/), and [GitHub](https://docs.github.com/en/get-started).
