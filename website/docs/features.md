# Features

Some of the key features of OpenEverest are:

## Deployments

- **Multi-cloud deployments**: deploy databases on Kubernetes in more than one cloud, for redundancy, high availability, and data sovereignty.
- **Multiple open source databases**: run supported engines on any Kubernetes cluster, in the cloud or on-premises.
- **Private / DIY control**: keep the database environment on infrastructure you operate.

## Database provisioning

- **Horizontal and vertical scaling**: scale out with more nodes or scale up a single node as load changes.
- **Storage class support**: pick Kubernetes storage classes that match performance and cost.
- **Disaster recovery**: on-demand backups, restore into an existing cluster, or create a new database from a backup.
- **Advanced engine configuration**: tune engine settings and external access without leaving the platform.

## Database management

- **Resource allocation**: change CPU and memory as workloads shift (vertical scaling).

## Administrative

- **Monitoring with PMM**: send metrics to Percona Monitoring and Management for query analytics and cluster health.
