# Join the community and get support

OpenEverest is supported by contributors, users, and professional service providers.

## Ask questions

Join real-time discussion on CNCF Slack: [#openeverest-users](https://cloud-native.slack.com/archives/C09RRGZL2UX).

## Community meetings

Join every two weeks for updates, demos, and Q&A. See the [meeting schedule](https://github.com/openeverest#openeverest-community-meetings).

## Contribute

All projects are Apache 2.0 licensed.

| Area | Description | Link |
| --- | --- | --- |
| **Code** | Platform engine, APIs, or CLI | [openeverest/openeverest](https://github.com/openeverest/openeverest) |
| **Documentation** | Guides and reference | [openeverest/everest-doc](https://github.com/openeverest/everest-doc) |
| **Blog and website** | Marketing site | [openeverest/openeverest.github.io](https://github.com/openeverest/openeverest.github.io) |

See the [contributing guide](contribute.md) in this PoC.

## Report issues

- [Open an issue](https://github.com/openeverest/openeverest/issues)
- [Start a discussion](https://github.com/openeverest/openeverest/discussions)

## Commercial support

For SLAs, 24/7 assistance, or consulting, see the [OpenEverest support page](https://openeverest.io/support).
